# 景停首頁｜正式版 v1.2

2026-10-02 更新為正式版 v1.2。正式入口是本目錄的 `index.html`；頁尾與 HTML metadata 標示 v1.2。`versions/v1.2/` 是目前正式版的獨立快照；舊版與其他歷史快照請勿直接修改。

## 預覽

從工作區根目錄執行：

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory Innisfree-site
```

開啟 `http://127.0.0.1:4173/`。公開站點使用 GitHub Pages：`https://moonest-0321.github.io/Innisfree/`。

## 目前範圍

首頁包含江南樓閣「景停」Logo、題句「張燈樓結綵 留風盼景停」、關於景停的故事、拾頁短詩與精選作品預覽示意，以及帆夢預覽區塊。首屏向量背景從故事中二樓亭閣向外看，以屋簷與欄杆框住雨幕、湖面、遠岸與小船。導覽順序是關於景停、拾頁、帆夢；首屏暫不展示只有待填內容的作品節錄與消息。拾頁預覽尚未連接作品資料；帆夢尚無經確認的公開下載位址，因此下載入口標示尚未開放。

交接資訊見 `HANDOFF.md`；修改流程和版本規範見 `WORKFLOW.md`。先前工作版保存在 `versions/v18-before-retained-selection/`，僅供參考，不是正式版。
